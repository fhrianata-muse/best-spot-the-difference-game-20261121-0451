Lantern & Lens is a spot-the-difference game drawn entirely on canvas: two near-identical hand-drawn pictures sit side by side, and you hunt what changed between them before the clock runs down. It plays across three scenes in one lantern-lit world — **Dawn Harbour** (7 differences), **Night Market** (9), and **Clockwork Observatory** (11) — **27 differences** in all, mixing colour changes, missing objects, moved objects and one extra lantern. Found differences are ringed on both pictures at once; hints are limited and cost points, mistakes cost points, and each scene is rated with stars when cleared. Play with the mouse (click a difference in either picture, hold Shift for a 2× loupe) or the keyboard (arrow keys move the brass ring, Enter checks the spot, H asks for a hint, Tab swaps panels). Everything is original and self-contained: the art is painted in code, the sounds are synthesised with WebAudio, and the game runs offline from static files with no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and press Play.
